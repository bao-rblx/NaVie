Project list
Category 1: Intelligent Agents & Problem Solving

These topics focus on foundational AI concepts like search, game theory, and constraint
satisfaction.

Project: Pathfinding in Complex Environments:
Implement and compare different search algorithms (e.g., A*, IDA*, bidirectional search,
local search like Hill Climbing or Simulated Annealing) on a complex map (e.g., a labyrinth,
a city map with traffic, a game level with obstacles).

   •   Possible Extensions: Implement pathfinding for multiple agents or incorporate
       dynamic obstacles.

Project: Game Playing AI:

Develop an AI agent to play a classic board game (e.g., Chess, Checkers, Othello, Connect
Four, Tic-Tac-Toe variant) using adversarial search algorithms (e.g., Minimax with Alpha-Beta
Pruning).

   •   Possible Extensions: Implement Expectimax for games with uncertainty (e.g.,
       simple card games), or use a neural network to evaluate board states.

Project: Constraint Satisfaction Problem (CSP) Solver:

Implement a CSP solver to tackle problems like Sudoku, N-Queens, map coloring, or a
simple scheduling problem.

   •   Possible Extensions: Explore different heuristics (e.g., MRV, LCV), pruning
       techniques (e.g., forward checking, arc consistency), or local search for CSPs.



Category 2: Knowledge, Reasoning, and Planning

These topics delve into logical agents, knowledge representation, and automated planning.

Project: Simple Logical Agent / Expert System:

Build a small rule-based system (e.g., using propositional logic or a simplified first-order
logic) for a specific domain (e.g., a simple medical diagnostic system, a recommender for a
small set of products, a basic animal identification system).

   •   Possible Extensions: Implement forward or backward chaining inference.

Project: Knowledge Representation and Querying:

Design a small knowledge base for a specific domain (e.g., family tree, geographic facts,
academic courses) using a chosen representation (e.g., logical predicates, semantic
network, simple ontology). Implement a system to query this knowledge base.

   •   Possible Extensions: Implement simple inference rules or consistency checking.
Category 3: Uncertain Knowledge and Reasoning

These topics focus on probability, Bayesian networks, decision-making, and multi-agent
systems.

Project: Bayesian Network for Diagnosis/Prediction:

Build a simple Bayesian Network for a small, well-defined problem (e.g., a simplified
medical diagnosis given symptoms, predicting weather, or simple equipment failure
diagnosis). Implement inference (e.g., enumeration, variable elimination, or Gibbs sampling
for larger networks).

   •   Possible Extensions: Use real-world (or realistically simulated) data to learn
       parameters.

Project: Decision-Making Agent (Utility Theory/MDPs):

Design an agent that makes decisions under uncertainty using utility theory or Markov
Decision Processes (MDPs). Examples could include a simple stock trading agent, a game
player in a stochastic environment, or a robot navigating a grid world with uncertain
outcomes.

   •   Possible Extensions: Implement Value Iteration or Policy Iteration.


Category 4: Machine Learning

Project: Supervised Learning for Classification/Regression:

Implement a fundamental supervised learning algorithm (e.g., Decision Trees, Naive Bayes,
K-Nearest Neighbors, or a simple Perceptron/Neural Network) from scratch (or using basic
libraries like NumPy) to solve a classification or regression problem on a public dataset (e.g.,
Iris, Titanic, Boston Housing).

   •   Possible Extensions: Compare different algorithms, implement cross-validation, or
       explore feature engineering.

Project: Reinforcement Learning (RL) in a Grid World:

Implement a basic RL algorithm (e.g., Q-learning or SARSA) to solve a simple navigation or
reward collection problem in a grid world environment.

   •   Possible Extensions: Introduce obstacles, stochastic actions, or different reward
       functions.

Project: Simple Clustering Algorithm:
Implement a clustering algorithm (e.g., K-Means, Hierarchical Clustering) to group data
points from a public dataset.

   •   Possible Extensions: Compare different clustering metrics, or visualize the clusters
       effectively.
